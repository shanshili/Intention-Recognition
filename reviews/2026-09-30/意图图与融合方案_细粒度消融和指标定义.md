## 一 先明确哪些实验在验证预测，哪些在验证部署

原意图图以预测误差训练边分数；融合方案进一步利用多视图和门控产生部署图。这里有两次不同的推断：边分数能帮助预测，不代表用它选择传感器就能提高观测收益；一个模块改善整个网络的预测，也不代表它改善了选点。因此安排三种实验方式。

| 实验方式 | 输入和输出 | 固定什么 | 适合验证什么 |
|---|---|---|---|
| A：预测结构实验 | 相同稀疏观测、观测标记、观测年龄 → 全节点未来流量 | 每个片段的观测集合及到达记录相同；数据、训练预算和输出头容量可比 | GAT、TCN、边消息、残差输出、节点及边特征是否帮助预测 |
| B：观测选择实验 | 决策时已有信息 → K 个节点 → 获取这些节点的后续新数据 → 全网预测 | 共同预测器及其权重、初始历史、预算和回放规则相同 | 意图评分、因果先验、融合门控和选择规则是否帮助选点 |
| C：完整系统实验 | 各方法自己的选择与预测流程 → 配置、预测、费用 | 数据权限、观测预算、目标节点、预测时距及评价代码相同 | 最终方案能否与外部方法竞争 |

A 中需要重新训练被修改的预测网络，不能一边删除 TCN，一边声称预测器权重完全固定。B 中改变的是选择器；如果选择器自身带有 GAT/TCN，可以重训它，但下游共同预测器仍固定。C 的收益可能来自选择与预测两方面，不能直接归给某个特征。共享预测器与完整系统分开比较，可参考 [AFABench](https://arxiv.org/html/2508.14734v3)。

主线在两小时片段开始时选一次，之后不换点。采用当前历史特征不等于采用动态部署。动态支线只是在同一协议中允许再次决策，随后才检验持续、新增、消退等变化特征。所有表中的“主线”均采用这个定义。

在正式消融前，先修正以下有效性问题。错误实现、未来信息和断开的训练路径不能作为正常的“无模块版本”。

| 需要先检查的事项 | 当前材料中的具体问题 | 实验前的处理 |
|---|---|---|
| 最终选点是否被任务训练 | 当前 RA 预测头使用图级融合表示；节点、边门控没有进入预测损失路径，独立节点评分头也未得到相应监督 | 让选点实际控制后续观测，并用其预测损失训练选择器；记录各评分模块的梯度及参数变化 |
| 图的时间可用性 | 笔记写入 $I^{t+r}$、未来延续性和未来变化量 | 在线版本只能使用截止决策时已到达的数据；若预测未来图，明确写成 $\widehat I^{t+r\mid t}$，单独验证预测误差。不能读取真实未来图 |
| 相关特征是否真的有效 | 当前小时级 W=3，而动态相关代码要求至少四对有效样本，相关部分会退化为零 | 独立设置相关估计窗口，记录有效配对数、缺失率和零方差；缺失估计加标记，不能悄悄当作相关为零 |
| 方向是否一致 | 笔记的源/目标维度、图文件维度及 GAT 聚合方向需要统一 | 用单边 $i\to j$ 的小例子核对读取、消息传递、评分和画图方向；不凭数组维度名称猜测 |
| 局部统计定义 | 笔记写 k 跳 ego-graph；当前代码按节点的入边与出边直接汇总 | 第一轮以“关联边统计”命名；若改为 k 跳诱导子图，作为独立替换实验 |
| “弹性效用”是否测到任务 | 当前随机删边后的剩余权重不能代替故障预测效果 | 真正屏蔽失效节点的新观测，重新回放预测，计算误差与恢复 |
| 节点部署与边部署是否同一动作 | 预测依赖边未必是通信链路，观测一个节点也不必同时观测其目标节点 | 主线预算只约束观测节点；边用于关系建模。只有明确通信动作、费用和依赖约束后，才单独研究边资源部署 |

上述工程问题可追溯至[已有代码审查](<D:/Tjnu-p/Mp/Intention Recognition/reviews/2026-09-28/当前方法_数学审查与2025-2026更新路线.md:278>)；局部统计可核对[当前实现](<D:/Tjnu-p/Mp/Intention Recognition/260731/modules/module3_gating.py:28>)。

## 二 消融按“基本模块—内部组件—特征组—单项”展开

消融的层级应当与方法章节一致。先说明方法由哪些理论模块组成，再检验每个模块的必要性；只有进入模块内部时，才讨论节点特征、边特征、某个视图或某个统计量。外部基线也按这套结构描述，才能看出它与本文在哪一层相同、在哪一层不同。

本方案采用下面的层级。层级表示问题的粗细，不表示所有因素都必须保留在最终模型中。

~~~text
共同任务：已有稀疏观测 → 预算内选点 → 获取后续记录 → 全网未来预测
│
├─ 第一层：基本模块与信息来源
│  ├─ 因果结构 C：是否引入因果先验
│  ├─ 意图图生成 I：是否显式学习有向任务关系
│  ├─ 多视图构造 V：是否拆分共识、意图残差、因果未激活
│  ├─ 多视图时空编码 E：是否需要专门的图与时间编码
│  ├─ 分层融合 F：是否需要按图、节点、边调整融合权重
│  └─ 预算选择 S：相同评分怎样转化为一组观测节点
│
├─ 第二层：基本模块内部的组件
│  ├─ I：节点辅助特征 / 边辅助特征 / 独立边评分与消息
│  ├─ V：当前联合视图 / 历史变化视图
│  ├─ E：空间传播 / 节点时间编码 / 图级池化与时间编码
│  ├─ F：图级门控 / 节点级门控 / 边级门控
│  │      表示输入 / 显式结构统计输入
│  └─ S：边到节点评分 / 独立节点评分 / 集合选择规则
│
├─ 第三层：特征组、单个视图与组件替代
│  ├─ 节点：时间特征 / 差分 / 季节残差
│  ├─ 边：几何 / 长期相关 / 窗口相关 / 异常与趋势
│  ├─ 视图：共识 / 意图残差 / 因果未激活 / 持续 / 新增 / 消退
│  └─ 门控统计：重合 / 分歧 / 历史稳定性 / 新增消退
│
└─ 第四层：单项与参数
   ├─ Pearson / 相关峰 / 最优时滞 / 方向差
   ├─ 源端 / 目标端特征，差向量 / 哈达玛积
   └─ 温度、阈值、窗口、候选边数、正则系数
~~~

C 是输入的结构先验，I 是一个模块的输出；不能把二者都模糊写成“加一张图”。关闭 I 要说明是关闭生成模块、改用一张固定图，还是仅不把 I 送入融合。三种操作回答不同问题。

### 2.1 先固定基础版本，后面的“增加”才有参照

**基础版本 B0**：输入已获取的流量历史、观测标记、观测年龄；使用共同时间编码器和普通节点评分网络，执行同一硬 Top-K，随后由共同预测器完成全网预测。它已经按预测任务训练，但没有因果先验、显式意图图、多视图或分层门控。

| 对象 | 最小配置 | 后续可以增加什么 |
|---|---|---|
| 节点输入 $N_0$ | 标准化流量历史、观测标记、观测年龄；统一合法插补 | 日内/星期编码、差分、季节残差 |
| 节点表示 $h_i$ | 共同时间编码器输出 | 空间传播、额外时间编码与池化方式 |
| 边输入 $E_0$ | 不提供额外边属性；候选边只限定可评分的节点对 | 几何、静态相关、窗口相关、异常、趋势 |
| 最小意图生成器 | 以有序端点 $[h_i,h_j]$ 计算关系分数 | 边特征、差向量、哈达玛积、独立消息传播与正则项 |
| 输入图 | C 仅用训练期估计；I 在当前合法历史上生成 | 替换 C 来源；替换 I 的生成方法；检查方向和时滞 |
| 最小多图处理 | C、I 各自经简单加权邻居聚合、普通池化，等权合成 | 派生视图、专门的时空编码、学习融合 |
| 预算动作 | 每个片段选 K 个，片段内不换点 | 冗余感知集合选择；动态支线允许更新 |

因此，“无节点辅助特征”仍保留 $N_0$；“无边辅助特征”仍保留有序端点与候选关系。这两类基础信息不能被删掉后，与一个能正常工作的方法比较。这里的边辅助特征指额外的几何和统计属性；C/I 的邻接与权重仍作为图结构使用，不能把“无边辅助特征”理解成“没有图关系”。

候选关系与关系权重分开：主对照先共用同一候选边集合。由坐标构建候选图后，再删除显式距离特征，只能说明“不直接输入距离”的效果，不能说完全没有利用地理信息。候选图来源和边数留到对应因素实验。

粗粒度实验先用 $N_0,E_0$。原方案额外拼接的特征在第二、三层逐步加入，避免“加意图模块”同时隐含增加十几种输入。

### 2.2 第一层：基本模块是否有必要

下面给出一条可复现的增加顺序。这些是内部参照版本，不是具体文献算法。编码器、评分接口和训练方法需要预先固定；新增模块的参数量与计算量同时记录。

| 版本 | 输入结构 | 相对参照版本只增加什么 | 主要比较 | 要验证的主张 |
|---|---|---|---|---|
| B0 基础选点 | 无 C/I；公共候选集合仅作约束 | 普通节点任务评分 | 对随机、覆盖、训练期固定配置 | 学习选点是否有价值 |
| BC 因果结构版 | C | 因果结构分支，简单聚合 | BC 对 B0 | 结构先验能否改善选点，特别是少量观测和关系变化场景 |
| BI 意图图版 | I | 最小有向意图生成器，简单聚合 | BI 对 B0 | 显式节点间任务关系是否超出普通节点评分 |
| BCI 简单融合版 | C、I | 两个分支并用，固定等权融合 | BCI 对 BC、BI | 两类信息是否互补 |
| BV 多视图版 | C、I 及三种当前派生视图 | 共识、意图残差、因果未激活视图；仍用简单聚合和等权融合 | BV 对 BCI | 显式区分一致与分歧是否比直接用两张图更有效 |
| BE 时空编码版 | 与 BV 相同 | 用多视图 GNN/TCN 替换简单聚合；仍等权融合 | BE 对 BV | 专门的时空编码是否值得其复杂度 |
| BF 分层融合版 | 与 BE 相同 | 图、节点、边的融合门控；先只用编码表示 | BF 对 BE | 按场景、区域和关系调整融合是否有效 |
| BS 集合选择版，按需开展 | 与 BF 相同 | 将 Top-K 换成考虑观测冗余的集合选择 | BS 对 BF | 好的单点排序之外，是否还需要显式处理集合冗余 |

B0、BC、BI、BCI 是图来源及意图生成模块的四组总体对照。BV、BE、BF 才对应后续大模块。**BF 是完整结构的雏形，尚不包含所有辅助特征；不能把它称作原方案所有设计均已验证的最终模型。**

如果把抗扰目标作为理论贡献，还要在第一层单独设置“仅平均预测目标”和“加入故障风险目标”的粗对照，固定全部结构和正常样本训练预算。之后才细分故障损失形式与系数；不能把这一目标变化只放在第四层当普通参数调整。

这一增加顺序不能单独证明最终模型中的模块都必要。确定一个包含候选组件的参照版本后，还要做反向删除：

| 从完整参照中删除什么 | 必须如何处理依赖 | 对应哪项正向比较 |
|---|---|---|
| C | 移除 C 分支，以及依赖 C 的共识、两类残差和相关统计；重建合法剩余流程 | B0→BC、BI→BCI |
| 意图生成模块 I | 移除生成器、I 及全部派生视图、统计；保留可用 C 路径 | B0→BI、BC→BCI |
| 多视图构造 V | 回到 C、I 两个基础视图；编码与融合接口采用相同规则 | BCI→BV |
| 专门时空编码 E | 用简单聚合和普通池化替代，保持输出接口可用 | BV→BE |
| 分层门控 F | 替换为等权或训练期学习的常数融合权重 | BE→BF |
| 复杂集合选择 S | 回到相同 K 的 Top-K | BF→BS |

删除大模块会连带移除其依赖组件，因此它衡量的是该模块及其使用路径的整体贡献。后续小模块消融才负责进一步归因。对容量差异明显的比较，补充加宽简单网络或共享编码参数的对照。

图来源还需要一个**普通任务学习图**作为替换参照。它与意图图都按下游损失训练、都使用相同信息和预算，但不设置本文特定的意图表示或监督。如果两者计算方式和训练目标完全相同，只是名称不同，就不存在可供实验检验的“意图创新”。

### 2.3 第二层：模块内部哪个组件起作用

本层不同时改变 C/I 来源、视图数量、特征组和门控层级。每一行明确父模块及局部参照。

| 父模块 | 本层因素与参照 | 比较版本 | 主要观察什么 |
|---|---|---|---|
| 意图生成 I | 相对 $N_0,E_0$ 的辅助输入 | 无辅助；仅节点辅助；仅边辅助；二者都有 | 节点信息、边信息各自的增益及互补；MAE、观测收益排序、成本 |
| 意图生成 I | 独立边评分相对普通 GAT 权重 | 均匀边权、复用 GAT 权重、独立意图评分 | 第二套关系评分是否必要；预测结构实验和选点实验分别报告 |
| 意图生成 I | 是否有最终边消息 | 保留/删除第二次消息传播，其他编码相同 | 分数是否确实帮助预测；不能以遮蔽边结果直接证明选点收益 |
| 多视图 V | 当前结构与历史变化结构 | C/I；加当前派生组；再在支线加历史变化组 | 当前分歧与时间变化是不是两种不同增益 |
| 时空编码 E | 空间和时间组件 | 普通聚合/GAT；节点末时刻/节点 TCN；普通图池化/图级 TCN，分开改变 | 邻居信息、节点历史、全图历史分别是否有用 |
| 时空编码 E | 参数组织 | 各视图独立编码、共享编码、同容量简单模型 | 多视图收益是否只是更多参数 |
| 融合 F | 门控粒度 | 等权、常数、图级、图+节点、图+边、图+节点+边 | 全局条件、局部区域和具体关系分别是否需要适应 |
| 融合 F | 编码表示与结构统计 | 仅表示、仅统计、表示+统计；另加简单密度统计替代 | 显式统计是否弥补表示压缩，还是只提供尺度/边数 |
| 选择 S | 节点评分来源 | 只图分数汇总、只节点 MLP、二者结合 | 图结构能否超出普通节点表示提供选点依据 |
| 选择 S | 独立排序或集合决策 | 同一输入价值模型的 Top-K、冗余感知选择 | 是否存在重复观测；若后者新增条件收益模型，需作为另一个因素披露 |

节点辅助组暂包括时间、差分和季节残差；边辅助组包括原方案的几何、长期相关及窗口统计。这一层先整体开关两类输入，下一层再分组。四种输入组合是同一个 2×2 实验，不能只比较“全部特征”与“无特征”。

**门控消融需要先定义可执行的替代版本。**原方案 $\gamma_i$ 通过边门控 $\omega_{ij}$ 生效，不能简单删除 $\omega$ 后仍说节点门控存在。建议采用下表，并公开替代规则。

| 门控版本 | 融合权重如何计算 | 参照关系 |
|---|---|---|
| 等权 | 每个视图权重相同 | BE 的默认版本 |
| 常数 | 全训练集学习一组权重，测试时不随片段变化 | 对等权，检验固定偏好 |
| 图级 G | $\alpha_{ij,m}=\pi_m$ | 对常数，检验当前场景条件 |
| 图+节点 GN | $\alpha_{ij,m}={\rm Norm}_m[\pi_m(\gamma_{i,m}+\gamma_{j,m})/2]$ | 对 G，检验节点局部调整 |
| 图+边 GE | $\alpha_{ij,m}={\rm Norm}_m[\pi_m\omega_{ij,m}]$，边 MLP 不输入 $\gamma$ | 对 G，检验直接的边局部调整 |
| 图+节点+边 GNE | 原完整路径；边 MLP 同时读取 $\gamma_i,\gamma_j$ | 对 GE，检验节点门控给边门控的额外帮助；对 GN，检验学习边组合是否优于固定端点组合 |

${\rm Norm}_m$ 表示沿视图维度归一化。GN 中的端点平均是为消融明确设置的简单替代，不冒充原方案已有公式。GE 与 GNE 的对应比较较干净；GN 与 GNE 包含“固定组合换为学习组合”的改变，应按这一含义解释。

另外，删除图级门控时，要在节点输入、边输入、节点融合及最终乘积中统一移除其作用，使用规定的等权替代。只删去一处 $\pi$ 输入，应称“去掉直接输入通道”，不能称“无图级门控”。

### 2.4 第三层：基础特征之外，哪一组值得增加

本层每次增加一个有明确作用的特征组。先比较“基础+该组”与基础，再比较“完整特征−该组”与完整特征，分别回答独立收益和条件增益。预期改善写在实验前，结果可以不支持预期。

| 父组件 | 基础参照 | 新增组 | 预期改善与针对性评价 |
|---|---|---|---|
| 节点辅助输入 | $N_0$ | 日内、星期周期编码 | 区分相同流量在不同时段的含义；看时段分组 MAE及对固定时间计划的增益 |
| 节点辅助输入 | $N_0$ | 一阶差分 | 提供短期增减趋势；看快速变化片段，而不只看总体平均 |
| 节点辅助输入 | $N_0+$时间编码 | 相对训练期季节均值的残差 | 识别偏离常规模式的状态；看异常与常规片段误差 |
| 边辅助输入 | $E_0$ | 距离、距离核、方位 | 提供关系的空间限制；看稀疏历史下的收益、远近节点分组及成本 |
| 边辅助输入 | $E_0$ | 长期 Pearson 与时滞相关组 | 提供长期关联与领先关系；看候选关系/方向诊断和选点误差 |
| 边辅助输入 | $E_0+$长期相关 | 窗口相关与窗口方向差 | 补充近期偏离长期关系的情况；看跨时期变化片段及短窗口估计噪声 |
| 边辅助输入 | $E_0$ | 两端异常幅度 | 使关系评分注意到偏离常态的源/目标；看独立观测收益，而非只看异常值是否大 |
| 边辅助输入 | $E_0$ | 两端趋势 | 提供变化方向；看上升、下降、先升后降等分组误差 |
| 关系表示 | $[h_i,h_j]$ | 差向量、哈达玛积，分别添加 | 检验显式差异与乘性交互；方向证据来自边级实际观测收益 |
| 图级门控输入 | 编码表示 g | C/I 重合与分歧统计 | 判断是否需要信任先验或当前任务关系；看预先定义的高分歧片段 |
| 节点门控输入 | 节点表示与图级权重 | 局部重合、局部残差统计 | 识别各区域不同的关系可靠性；看局部故障和区域异质性 |
| 边门控输入 | 两端表示与当前有效门控 | 各视图该边的显式权重 | 让门控直接知道边在各图中的状态；与只用表示比较 |
| 动态支线的门控 | 当前关系表示与当前统计 | 持续、变化、新增、消退统计 | 判断更新是否值得；看更新收益、切换次数与恢复，不能只看图变化幅度 |

“基础参照”可以因假设不同而不同，但必须明确。例如窗口相关应优先对比“已有长期相关”，才能回答它有没有提供额外的短期信息，而不只是回答“相关特征有没有用”。

特征进入模型的位置也要单独控制。原方案边特征同时进入 GAT 和边评分器，因此设置“都不输入、仅进 GAT、仅进边评分器、两处都进”四组。在确认主要有效位置前，不能把只删除一处的结果叫作整组特征消融。

**多视图单独形成一条增加路线，不与特征组同时改变。**

| 视图版本 | 与哪个参照比 | 要验证的具体作用 | 必须保留的替代对照 |
|---|---|---|---|
| 两张基础图 C、I | 单独 C、单独 I | 先验与任务关系能否互补 | 固定相加或等权编码 |
| 基础图+共识 CI | C、I | 双方共同支持是否更可靠 | 同容量两视图模型；不能把重合本身当正确答案 |
| 基础图+意图残差 $R_I$ | C、I | 先验漏掉的任务关系能否帮助选点 | C 漏边/失准条件，并检查纯噪声条件是否受损 |
| 基础图+因果未激活 $R_C$ | C、I | 当前评分未重视的稳定结构是否帮助抗故障 | 实际节点失效回放，衡量故障 MAE和尾部误差 |
| 基础图+上述三种当前派生视图 | 各自单加及两张基础图 | 三种作用能否组合；是否存在重复 | 从完整当前视图逐一删除，编码共享与容量对照 |
| 支线：当前 I+过去 I | 仅当前 I | 首先检验多看一张过去图是否有用 | 相同可用历史和输入维度 |
| 支线：持续 P | 当前+过去 I 的直接编码 | 特定的共同部分表示是否方便选点 | 相同信息直接输入；同样更新周期 |
| 支线：新增 N | 当前+过去 I 的直接编码 | 新出现关系是否帮助跟踪短期需求 | 有符号图差；P/N 分别和共同加入 |
| 支线：消退 E | 已有变化信息、无 E 输入 | 衰减关系是否帮助减少无效保留 | 原方案 E 仅作特征；若把 E 编为第八视图，另列实验 |

原七个编码视图是 C、I、CI、$R_I$、$R_C$、P、N，消退 E 不在其中。主线先到五个当前视图，动态支线再扩展历史关系。也可以在一次选点前使用历史变化信息，但应单独注明，片段内保持不换点，避免混淆“历史特征”与“动态动作”。

还要注意：派生视图由 C/I 确定计算，并不增加新的原始观测。实验检验的是这种表示方式是否更容易利用原信息。尤其 $P+N=I_t$，因此必须比较“显式持续/新增”与“直接输入当前/过去 I”，不能只与没有历史输入的弱版本比较。

### 2.5 第四层：最后才拆单项，调整公式和参数

这一层继承上层已经明确的参照。单项删除后没有下降，可能是同组其他特征替代了它；因此结合组级删除和少量关键交互解释，不能机械地逐项淘汰。

| 所属组或组件 | 再细分哪些项 | 必要的验证或数学约束 |
|---|---|---|
| 节点时间组 | 日内 vs 星期；时间进入 GAT vs 只进后端 | sin/cos 成对处理；5 分钟数据用日内时间槽，并比较小时编码 |
| 节点状态组 | 差分、季节残差的独立和共同作用 | 季节均值只从训练集拟合；派生统计不代表新增独立信息 |
| 几何组 | 距离、距离核、方位 | 距离与核做 2×2，方位成对删除；地理距离单位明确 |
| 长期相关组 | Pearson、最大时滞相关、最优时滞、正反向差 | 每项删除；Pearson/时滞组替换；峰值与时滞交互；不称为物理因果真值 |
| 窗口相关组 | $D_{ij}$、$D_{ij}-D_{ji}$、有效性标记 | 记录有效样本、方差和缺失；“无有效估计”不等于零相关 |
| 异常与趋势组 | 源端、目标端、两端共同 | 区分源的观测价值与目标预测难度；均值差分实际上是首尾变化 |
| 关系表示 | $h_i-h_j$、$h_i\odot h_j$ | 已有有序端点且后续为无约束线性层时，差向量可被重参数化，不增加函数表达能力；乘积是对称交互 |
| 图级结构统计 | 重合、意图残差比例、因果未激活比例 | 逐项增加/删除；用密度、总权重替换整组，排除尺度解释 |
| 历史统计 | 持续、变化、新增、消退 | 不允许输入真实未来图；分母近零给规定值与有效性标记 |
| 节点局部统计 | 五项分别删除；关联边、1/2 跳范围 | 明确当前实现是关联边汇总；持续/新增比例近似互补时检查冗余 |
| 边级显式输入 | C、I、CI、$R_I$、$R_C$、P、N、E | 只删权重输入与删除整个视图是两种实验；后者还要移除编码和派生统计 |
| 编码细节 | 普通/扩张 TCN；最后/平均/注意力池化；GAT 自身残差 | 记录感受野和参数量；压缩窗口发生在哪一步必须写清 |
| 融合细节 | 直接权重/硬掩码/软掩码；固定/逐窗归一化 | 软掩码非互斥分解；逐窗归一化可能制造表观变化 |
| 门控组合 | 乘积归一化与 logits 相加 | 两个 softmax 相乘再归一化在同支持下等价于 logits 相加后 softmax，不把等价运算当新能力 |
| 节点分数 | 出边、入边、入+出、额外 MLP | 在同预算真实回放中判断；高入度不必等于高观测价值 |
| 预测头 | 直接预测 vs 残差预测 | 输入与输出维度相同；未观测节点不使用当前真实值作残差基准 |
| 损失 | MAE/MSE/Huber；稀疏、双向惩罚、故障损失、追踪项 | 一次改变一项。稀疏与归一化做交互；低互惠率或与 I 相似不能替代外部效果 |
| 参数 | k、相关窗口、阈值、温度、正则强度 | 验证集敏感性分析，测试配置冻结；参数调优不与模块级消融混为一谈 |

参数的具体最优取值留到验证集确定。没有新增数据与实验前，不预言哪组特征必然带来改善。

以上层级包含两条互相校验的路线：从基础逐步增加，验证设计动机；从最终参照逐层删除或替换，验证条件贡献。先做组级证据，再定位单项。若某因素直接对应论文核心主张，例如有向关系或因果时滞，即使其上层组平均增益较小，也应完成针对性检验并报告负结果。

## 三 已有论文的指标：哪些沿用，哪些需要改写

下面针对附件的公式定义作审查，不据此推断旧实验代码一定如何实现，也不对旧数值重新作结论。若代码已采用正确版本，应修正文稿，使二者一致。

| 附件指标及位置 | 具体问题 | 本次采用方式 |
|---|---|---|
| P/R/F1，式(29) | 基本形式成立，但需统一边是 $(i,j)$ 还是 $(i,j,\ell)$，并说明空集合、反向边、自回归边和阈值 | 保留，按下一节的固定评价全集计算；有向边与时滞边分别报告 |
| wER，式(30) | 公式只有真边是否找回及参考权重，没有预测权重误差；不能支持“估计因果强度准确” | 改称“按真实强度加权的召回”。参考权重必须来自生成真值；边权误差另测 |
| sNR，式(31) | 多个真实节点可以匹配同一个预测节点；只看召回，不惩罚多选；距离与温度单位未充分约定 | 固定 K 时可作为空间覆盖描述。若声称节点识别，采用一对一匹配后的软 P/R/F1，并写清距离单位 |
| sER，式(32) | 求和及最大值的取值集合不完整；边与节点的距离对象混杂；源、目标、时滞对应不明确；多对一匹配同样可能虚高 | 重新定义有向端点与时滞相似度，再做一对一匹配；只作为近似定位辅助指标 |
| RMSE，式(33) | 形式正确，但重构当前状态与预测未来不同；未在公式中明确预测时距、有效真值、已观测/未观测目标 | 保留并按 $h=15/30/60$ 分钟分别计算；所有方法评价同一全网目标 |
| Ent=$\log\det{\rm Cov}(X_{V_s})$ | 不是一般分布的熵；高斯差分熵还含常数与 1/2 系数；受单位、节点数、奇异协方差影响；不是目标预测信息量 | 如保留，命名为“标准化正则协方差 log-det”，固定 K，仅作多样性描述，不作意图正确性指标 |
| EC，式(34) | 边长之和单位是距离，不是焦耳；预测关系边不必对应通信边；双向边可能重复计物理连接 | 改称总连接长度。主任务另记录查询量、字节数和真实动作费用；有校准硬件模型后才报告能耗 |
| 密度 D，式(35) | 仅适用于无自环简单有向图；多时滞边不能直接代入；动态改变节点全集会改变含义 | 保留作结构描述，固定节点全集并明确是否折叠时滞。密度小不自动更好 |
| Reciprocity、H，式(36) | 双向边按边还是按边对计数不清楚；低互惠/高层次性不能证明因果正确；滞后反馈折叠后可成环 | 明确计数规则；只描述结构。以真图匹配和任务误差验证因果价值 |
| V-structures、源/汇节点 | 普通 $i\to j\leftarrow k$ 不一定是因果发现所指的未屏蔽碰撞结构；需检查 i、k 不相邻。孤立点也可能同时被计作源、汇 | 若保留，明确图类型、未屏蔽条件、无序父节点对及孤立点处理；不把数量越多/越少当正确性 |
| AR，式(37) | BFS 只是图上的可达范围；没有生成机制就不能等同于真实干预影响；删掉边会机械地降低 AR | 改称可达范围。故障影响主要看预测误差；有仿真干预真值时才评估影响区域识别 |
| Specificity $S_\Delta$，式(38) | 等于 $1-AR/\vert V_{\rm pred}\vert $，与 AR 完全线性相关；没有负样本或真实受影响标签，并非统计学特异度或溯源准确率 | 不再以“特异度/溯源准确率”使用，也不与 AR 算两个独立维度。真正特异度必须是 TN/(TN+FP) |
| 全局效率，式(39) | 对 $(i,j)\in E_{\rm pred}$ 求和漏掉经多跳可达的非邻接节点对；几何距离也不等于图上最短路径距离 | 改为固定节点全集所有有序对的最短路径倒数平均，见下一节；方向和边长度定义必须明确 |
| 保持率 Q，式(40) | 如果删节点后改变分母，或删边前图的效率为零，比例无法直接比较；图效率保持不等于预测保持 | 保留为辅助结构量时固定删前节点全集、失效节点按不可达处理，分母零记不适用；主要报告故障预测曲线 |
| POI 验证 | 附近 POI 多可以说明空间关联，不能独立证明因果枢纽或观测价值 | 若保留，固定半径、POI 类别和匹配对照，只作案例解释，不进入综合排名 |

全局效率的通常定义使用所有节点对的最短路径倒数；NetworkX 官方函数支持的图类型和权重处理也有具体限制，不能把库函数名当作公式实现保证。[官方全局效率说明](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.efficiency_measures.global_efficiency.html)、[互惠率说明](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.reciprocity.reciprocity.html)

数据身份也需要核对。附件把“PeMSD7(M)、228 节点”和“2025 年 1—7 月自行筛选、小时聚合、100 节点”连在一起；STGCN 作者公开的 PeMSD7 数据说明对应 2012 年 5—6 月工作日速度记录。如果当前使用的是另外下载的 2025 年流量，应使用自建 PeMS 子集名称，列清原始站点、字段与筛选规则，不能沿用公开基准名称让读者误以为是同一数据。[原数据作者说明](https://github.com/VeritasYin/STGCN_IJCAI-18)

## 四 新评价体系的输入、公式和输出

### 4.1 统一数据接口

原始目标为 $X\in\mathbb R^{T\times N}$，第一轮只预测交通流量一个变量。原始有效真值标记为 $M\in\{0,1\}^{T\times N}$。节点是否被选中、是否成功上报、记录何时到达另存，不能用 M 代替。

对片段 e，在预测发布时刻 t，模型依据截止 t 已到达的稀疏历史 $\mathcal H_{e,t}$，输出
$\widehat X_{e,t}\in\mathbb R^{3\times N}$，分别对应未来 15、30、60 分钟。
5 分钟数据的步数为 $h\in\{3,6,12\}$，标签为 $y_{e,t,h,i}=X_{t+h,i}$。
评价有效性为 $m_{e,t,h,i}=M_{t+h,i}$，它独立于选择器。
每个发布时刻及未来目标都落在所属时间划分内。

选择输出为 $a_{e,u,i}\in\{0,1\}$，表示时隙 u 是否请求节点 i 的新数据；
无故障时 $\sum_i a_{e,u,i}=K$。
主线片段内 a 不变，支线可变。
原始缺失导致没有可靠真值时，从所有方法对应位置的误差计算中共同排除，报告数量；不能把零流量一概当缺失。

因果输出单独保存为 $\widehat A^C_{ij\ell}$ 或其评分；意图输出保存为 $s_{e,i}$ 或 $s_{e,ij}$；融合部署分数保存为 $S^D_e$。这三者不能混用为“预测因果图”。

以下指标都返回每个数据集、预算、条件和种子的结果，再报告均值和不确定性。指标分六类；结构描述列在最后，不承担主要性能证明。

### 4.2 任务效果：预测全部节点是否更准

定义 $\Omega_h=\{(e,t,i):m_{e,t,h,i}=1\}$。反标准化后计算：

$$
{\rm MAE}_h=\frac1{|\Omega_h|}\sum_{\Omega_h}|\widehat y_{e,t,h,i}-y_{e,t,h,i}|,\qquad
{\rm RMSE}_h=\sqrt{\frac1{|\Omega_h|}\sum_{\Omega_h}(\widehat y-y)^2}.
$$

输入是同一目标集合上的预测、真值和有效标记；输出为一个非负标量，单位与流量一致，越低越好。主指标是 ${\rm MAE}_{6}$，即 30 分钟 MAE。MAE/RMSE 可参照 [MoGERNN](https://arxiv.org/abs/2501.12281) 和 [VIP](https://arxiv.org/abs/2510.24027) 的部分观测预测评价，但本文的片段与采集协议另行定义。

每片段损失为

$$
L_e(S)=\frac{\sum_{t,i}m_{e,t,6,i}|\widehat y_{e,t,6,i}(S)-y_{e,t,6,i}|}
{\sum_{t,i}m_{e,t,6,i}}.
$$

若某片段没有任何有效目标，其损失不定义，按对所有方法相同的预定规则共同排除并报告；不能用 0 代替。

同时报告片段等权均值 $\bar L=E^{-1}\sum_e L_e$，用于配对统计和选择器训练。全局 MAE 按有效目标数加权，$\bar L$ 按片段等权；真值缺失率不同时二者不必相等，表头必须标明。验证选模型使用 $\bar L$，不能在两种聚合间挑更好的一个。

与预先指定基线 B 比较：

$$
\Delta L=\bar L_{\rm method}-\bar L_B,\qquad
{\rm Improvement}=100\frac{\bar L_B-\bar L_{\rm method}}{\bar L_B}\%.
$$

基线误差为零时相对改善不定义，只报告绝对差。

另外报告未被当前观测的目标 MAE、预先划定区域 MAE、正常/突变片段 MAE。前一种分组因各方法选点不同，成员也会不同，属于各自系统诊断；不能替代同一全网目标主比较。要直接比较区域能力，区域集合由数据或外部标准预先固定。

MAPE 可省略。若为对齐文献而报告，规定仅使用 $|y|>\epsilon_y$ 的有效目标：
${\rm MAPE}=100\,{\rm mean}(|\widehat y-y|/|y|)$；
$\epsilon_y$ 按原始单位在验证前固定，报告排除比例。不要默认为零值有效，也不要只给公式而不写阈值。

### 4.3 因果证据：图是否识别正确，模型是否确实使用它

首先指定真值。完整因果发现用生成方程中的全部真实关系 $E^*$；核心提取用事先定义的 $E^*_{\rm core}$。不能把完整真边中不属于“核心”的关系全计作发现算法的错误，也不能把自定义“hub 节点”直接视作最优观测节点。

以正时滞为主，固定评价全集
$\mathcal U=\{(i,j,\ell):i\ne j,\ell=1,\ldots,L_C\}$。
自回归关系 $i=j$ 单独评估；瞬时关系另设满足相应假设的实验，不和滞后边混算。候选图排除的真边仍应在总召回分母中，不能通过缩小评价全集抬高结果。

给定真值边集 $E^*$ 和预测边集 $\widehat E$：

$$
TP=|\widehat E\cap E^*|,\quad FP=|\widehat E\setminus E^*|,\quad FN=|E^*\setminus\widehat E|,
$$
$$
P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad
F1=\frac{2TP}{2TP+FP+FN}.
$$

输出为 [0,1]，越高越好。预测为空而真值非空时规定 P=0、F1=0；真值为空时 R 不适用，另报 FP；两者均空时 F1 不适用。阈值在验证集选择并冻结，不取测试集最大 F1 冒充可部署效果。

至少分别报告：

- **时滞边 F1**：按三元组匹配，检查方向和滞后。
- **有向边 F1**：仅在双方分别合并时滞后，按 $(i,j)$ 匹配。它不能证明时滞正确。
- **Average Precision（AP）**：对每个不同评分阈值产生的 P/R，计算 $\sum_k(R_k-R_{k-1})P_k$。并列分数同组处理；真值为空时不适用。输出 [0,1]，减少依赖单一阈值，仍需保留部署阈值下结果。
- **时滞邻接差异**：
  $$
  H_{\rm lag}=\sum_{u\in\mathcal U}|\mathbf1[u\in\widehat E]-\mathbf1[u\in E^*]|.
  $$
  输出错误项数，越低越好。这里反向一条单向边通常产生一次删除和一次添加，错一个滞后同样通常计 2。为避免 SHD 实现歧义，按这个明确名称报告，不含糊声称采用统一 SHD。
- **候选图召回**：$R_{\rm cand}=|E^*\cap E_{\rm cand}|/|E^*|$。它说明搜索范围能覆盖多少真关系，与最终识别召回分开。

旧 wER 可修订为

$$
{\rm wRecall}=\frac{\sum_{u\in E^*\cap\widehat E}|w^*_u|}
{\sum_{u\in E^*}|w^*_u|}.
$$

输入的 $w^*$ 必须是独立参考强度，分母为零时不适用。它仍然只衡量覆盖，不衡量 $\widehat w-w^*$。只有模型确实估计了与生成系数相同含义、相同尺度的量，才能另报
${\rm WeightMAE}=|\mathcal U|^{-1}\sum_{u\in\mathcal U}|\widehat w_u-w^*_u|$。
偏相关、显著性、注意力权重一般不能直接与结构方程系数作这个比较。

已知机制的时序评估可参考 [TimeGraph，KDD 2025](https://arxiv.org/abs/2506.01361)；真实外部关系参考的困难可参照 [CausalRivers，ICLR 2025](https://arxiv.org/abs/2503.17452)。SID 需要相应的干预模型与图类型，本轮不强行加入。[SID 原论文](https://arxiv.org/abs/1306.1043)

在真实交通数据上，主要检查图来源、方向、时滞及先验错误的对照是否改变观测收益和预测结果。**如果 C 在 C-only 与 C+I 中完全相同，其因果识别指标也相同。没有理由要求融合版本在这些指标上更高。**反过来，若模型没有输出可解释为因果结构的估计，因果 F1 应填“不适用”，不能填零后给它排名。

### 4.4 意图与选点：高评分是否对应真实观测收益

共同预测器 P 在这一组评价中固定。对同一初始历史、同一背景集合 S，分别回放“不额外观察 i”和“额外持续观察 i”。定义

$$
g_{e,i}(S;P)=L_e(S;P)-L_e(S\cup\{i\};P),\quad i\notin S.
$$

输入为 P、初始稀疏历史、两套合法采集动作、后续轨迹及评价真值；输出单位为流量 MAE 的下降量，可能为负。它是实现后的收益样本，不是无噪声的条件期望真值，也不是对交通状态的物理因果效应。

主线中 S 固定到片段末尾。第一轮用空 S，再用公共、预先抽取的 K−1 个背景节点集合。背景集合不得根据某方法的测试评分挑选，所有方法复用。采样片段过多导致成本高时，按训练前规定的正常/变化分层随机抽样，报告抽样量和回放费用；不只检查高分节点。

| 指标 | 公式、输入与输出 | 能说明什么 |
|---|---|---|
| 收益排序相关 | 对每个 e、S，在同一候选节点集上计算 $\rho_g={\rm Corr}({\rm rank}(s_i),{\rm rank}(g_i))$，并列取平均秩。输出 [-1,1] | 高分是否对应较大收益。评分或收益常数时不定义，报告无效比例 |
| 收益估计误差 | 仅当输出已标定为损失下降量：${\rm GMAE}={\rm mean}_{e,S,i}\vert \widehat g_{e,i}-g_{e,i}\vert $ | 是否估计对收益大小。注意力任意权重不能直接代入；标定只使用训练/验证集 |
| 前 k 个节点的实际平均收益 | ${\rm Gain@k}=(Ek)^{-1}\sum_e\sum_{i\in{\rm TopK}(s_e)}g_{e,i}(\varnothing)$ | 排名前部是否有用；保留负值，与随机/普通评分比较。它不是整组联合收益 |
| 集合实际误差 | 对真正选出的 $S_e$ 计算 $\bar L(S_e)$ 及相对基线改善 | 是否最终选对一组节点，包含节点间冗余影响 |
| 小规模事后差距 | $R_e^{\rm hindsight}=L_e(S_e)-\min_{\vert S\vert =K}L_e(S)$ | 同预测器、同片段下距离事后最佳集合多远；未来信息只用于诊断。大规模贪心参考不具备最优保证 |

这些是依据本课题“观测价值”定义制定的评估协议，不能包装成文献已有的统一“意图准确率”。特别是 Gain@k，不等于通常的分类 Precision@k。

若主张**有向边意图**，还必须验证边，而不只验证节点。固定目标 j 的片段损失 $L_{e,j}$，定义

$$
g_{e,i\to j}(S;P)=L_{e,j}(S;P)-L_{e,j}(S\cup\{i\};P).
$$

分别检验 $s_{ij}$ 与 $g_{i\to j}$ 的排序，并检验差值
$s_{ij}-s_{ji}$ 是否与 $g_{i\to j}-g_{j\to i}$ 对应。
背景 S 排除 i、j，两个方向使用同一 S；目标有效真值规则相同。
不把所有边打平成独立样本，先按片段/目标汇总，再按天统计。
如果要评价收益大小或差值符号，应先说明评分的跨源、跨目标尺度是否可比；逐目标归一化权重可能只能支持同一目标内部的排序。
即使排序有效，也只能称为有向观测贡献，不自动是车辆行驶路径。

小规模验证建议 N=12、K=3，枚举 220 个集合。若用合成数据，可对同一初始状态重复生成未来过程，以区分稳定的预期价值与偶然实现收益。真实数据没有重复未来，报告多片段统计及区间，不宣称恢复了唯一真实意图。

### 4.5 抗扰表现：故障后是否维持任务

对故障强度 $\gamma$、故障实例 r，记 $L_{e,r}^{\gamma}$ 为回放损失，同一方法、同一片段无故障损失为 $L_e^0$。输入为预先保存的故障掩码/延迟表和整条预测结果。

$$
D(\gamma)={\rm mean}_{e,r}(L_{e,r}^{\gamma}-L_e^0),\qquad
L(\gamma)={\rm mean}_{e,r}L_{e,r}^{\gamma}.
$$

二者都报告：只看增幅小，会让正常情况下已经很差的模型显得稳健。主比较使用对所有 N 个设备事先生成的同一故障场；另外可报告“已选节点失效固定比例”的条件试验，但不要混淆两种抽样方式。故障节点真实交通标签在离线评价端仍保留；实际记录本来缺失而无真值的位置仍排除。

在预先给定网格 $0=\gamma_0<\cdots<\gamma_J=\gamma_{\max}$ 上，定义平均故障误差曲线面积：

$$
{\rm AURC}=\frac1{\gamma_{\max}}\sum_{j=1}^J
\frac{L(\gamma_j)+L(\gamma_{j-1})}{2}(\gamma_j-\gamma_{j-1}).
$$

输出与 MAE 同单位，越低越好。初始网格可设 0、0.1、0.3、0.5；这一简称在本文明确指上述故障曲线，不与其他领域同名量混用。

对于最差片段表现，使用片段损失 Z 的经验上尾 CVaR：

$$
\widehat{\rm CVaR}_{0.9}
=\min_{\eta}\left[\eta+\frac1{0.1n}\sum_{b=1}^{n}(Z_b-\eta)_+\right].
$$

n 是当前条件下的片段/故障实例数量；输出为流量误差，越低越好。它描述最差约 10% 的风险。样本量小时要显示区间，不能把一个极端片段当作稳定结论。

只有研究**真实干预影响识别**时，才新增受影响集合的 Precision/Recall/F1 和 Specificity。此时先由已知仿真机制，在相同外生噪声下比较干预/未干预轨迹，并按预定目标时段、效应阈值定义受影响节点标签；Specificity=TN/(TN+FP)，分母零时不适用。仅对传感器输入遮蔽，不足以产生交通因果干预标签。

### 4.6 资源与动态表现：改善付出了多少代价

保存请求动作 a、成功回传标记 b、实际字节数、选择调用记录及新旧集合。基本资源量为

$$
C_{\rm req}=\sum_{e,u,i}a_{e,u,i},\quad
C_{\rm recv}=\sum_{e,u,i}b_{e,u,i},\quad
C_{\rm rep}=\frac12\sum_{e,u>u_0}|S_{e,u}\triangle S_{e,u-1}|.
$$

前两项单位为记录数；最后一项在固定 K 时是替换节点次数。初始轮询费用单列并计入总开销；即使对方法间差值抵消，也需公开。节点缺失或失败可能导致请求不成功，不能把失败请求当免费。若 K 变化，用开、关两个动作数单独计费。

有可解释的真实费用时：

$$
C_{\rm total}=
\sum c^{\rm req}_{i,u}a_{i,u}
+\sum c^{\rm on}_i\mathbf1[a_{i,u-1}=0,a_{i,u}=1]
+\sum c^{\rm off}_i\mathbf1[a_{i,u-1}=1,a_{i,u}=0]
+C_{\rm communication}.
$$

各项不能重复计费，并先换到同一费用单位。没有硬件或计费依据时，分列记录数、字节、切换数和计算时延，不给出虚构焦耳数。训练时长、总参数、峰值显存、特征计算/选点/预测时间分别记录；在线时延报告中位数及 P95，并注明硬件、批量、预热和负载。

动态收益为同一模型同一片段的

$$
G_e^{\rm update}=L_e^{\rm fixed}-L_e^{\rm update}.
$$

并列报告平均更新收益、替换数和总费用，绘制误差—切换、误差—预算曲线。Jaccard
$J(S_u,S_{u-1})=|S_u\cap S_{u-1}|/|S_u\cup S_{u-1}|$
仅表示配置变化，两集合都空约定为 1；变化更多或更少本身都不是效果好。

如果报告恢复时间，先固定故障起点 $u_0$、误差平滑窗、容忍增量 $\delta_{\rm rec}$、连续达标轮数 q。定义

$$
T_{\rm rec}=\min\{u-u_0:\widetilde L^{\gamma}_{u+v}
\le\widetilde L^{0}_{u+v}+\delta_{\rm rec},\
v=0,\ldots,q-1\}.
$$

$\widetilde L$ 是相同预测时距的滑动平均误差；允许用未来评价标签做事后计时，不能用于在线触发。观察期内未恢复的片段标为右删失，报告未恢复比例，不丢弃后只算成功均值。故障结束后恢复还是故障持续期间重新配置恢复，应在实验表中预先区分。

### 4.7 结构描述：保留有用信息，但限制结论

只有在论文需要分析图形态时报告这些量，不要求所有方法都计算，也不进入主性能总分。

对固定节点全集 V 的无自环简单有向图 G，令 n=|V|、m=|E|：

$$
{\rm Density}=\frac{m}{n(n-1)},\qquad
\rho=\frac{|\{(i,j)\in E:(j,i)\in E\}|}{m},\qquad
H=1-\frac{|\{e\in E:e\text{ 位于至少一个有向环上}\}|}{m}.
$$

一对双向边在 $\rho$ 分子计两条。m=0 时 $\rho,H$ 不适用；n<2 时密度不适用。时滞图先明确是否折叠；折叠产生的环与时间展开图中的环不同，不能据此否定真实滞后反馈。

连接长度为 ${\rm Length}=\sum_{(i,j)\in E_{\rm physical}}d_{ij}$，仅计算真正要建设或使用的物理连接；双向共用一条物理链路时只计一次。没有物理链路模型时，不对意图边求和后称能耗。

全局效率的本研究有向版本为

$$
E_{\rm glob}(G;V)=\frac1{n(n-1)}\sum_{i\ne j\in V}\frac1{d_G(i,j)}.
$$

这里 $d_G$ 为按方向的最短路径距离；不可达时取 $1/\infty=0$。采用无权 hop 时无量纲，采用正的物理长度时单位为长度倒数。因果置信分数不天然等于边长度；要用其倒数需另行解释。删除失效点后仍保留原 V 作为分母，相关节点对按不可达处理，才计算 $Q=E_{\rm after}/E_{\rm before}$；删前效率为零时 Q 不适用。

如果需要空间软匹配，令真边 $u=(i,j,\ell)$、预测边 $v=(p,q,k)$，

$$
K(u,v)=\exp\left[-\frac{d(i,p)+d(j,q)}{\mu_d}
-\frac{|\ell-k|\Delta t}{\mu_\tau}\right].
$$

源匹配源、目标匹配目标，$\mu_d$ 为距离单位、$\mu_\tau$ 为时间单位。
在两边集合之间求最大总相似度的一对一匹配 $\mathcal M^*$，令
$Q_{\rm soft}=\sum_{(u,v)\in\mathcal M^*}K(u,v)$，
$P_{\rm soft}=Q_{\rm soft}/|\widehat E|$、
$R_{\rm soft}=Q_{\rm soft}/|E^*|$，再取调和均值。
空集合沿用硬匹配约定。节点软匹配用 $K(i,p)=\exp[-d(i,p)/\mu_d]$。
这是本方案对旧式(31)(32)的修订定义，应明确标注；软匹配仍不能替代精确方向/时滞 F1。

如保留协方差 log-det，以训练期标准化值、固定长度评价窗口及固定 K 计算
$\log\det(\widehat\Sigma_S+\lambda I_K)$，$\lambda>0$ 预先固定，报告缺失估计办法。即使它更大，也只说明这一协方差准则下更分散，不能证明对未来全网目标的信息更多。

**综合评价的方式**是先看同预算主任务改善，再检查故障与费用约束，最后用因果/意图指标解释机制。不同来源和量纲的指标不任意相加。因果图正确但选点无收益、选点有效但方向解释不成立，都应允许成为最终结论。

## 五 基线按同一套层级维度筛选

本轮先规定需要什么类型的基线，暂不确定论文名单。基线与消融共用描述维度，但承担的证据不同：外部算法检验整体竞争力；同框架替换或内部消融，才适合把变化归因于某个模块。两篇算法同时在编码器、监督和输入上不同，不能把误差差异直接归因于“有无意图”。

### 5.1 先检查任务可比，再记录模块差异

| 比较层级 | 必须登记的维度 | 本研究的参照 | 对外部算法怎么处理 |
|---|---|---|---|
| 任务条件 | 预测/重构；目标节点；时距；可见历史；预算；动作频率 | 部分观测、全网未来预测、相同 K、主线一次配置 | 先统一条件；任务不一致且无法合理适配时，只作相关工作或组件参照 |
| 基本机制 | 是否按下游任务选点；C 来源；是否生成任务图 I；是否多视图 | B0、BC、BI、BCI、BV | 找结构功能相近而关键机制不同的算法 |
| 模块组件 | 时空编码；节点/边辅助输入；融合粒度；选择规则 | BE、BF、BS 及第二层版本 | 记录共同组件和差异组件；必要时实现共享骨干的替换版本 |
| 特征与监督 | 节点特征组；边特征组；图统计；额外收益标签或预训练 | $N_0,E_0$ 及第三层增量 | 确认可见信息一致；额外监督和数据量单列 |
| 实现与资源 | 维度、参数、优化器、调参预算、时延、训练费用 | 公共实验配置 | 允许原方法保留合适结构并充分调优；做容量/费用说明 |
| 动态扩展 | 谁决定更新时间；是否收费；是否补历史；是否重训 | 固定与周期/事件更新 | 与主线单列；不能把给定缺失掩码等同于主动调度 |

前两层决定“是不是同类问题及合理对照”，后几层解释“还存在哪些差异”。不能为了只差一个模块，把外部强方法改弱；原版公平适配结果与统一骨干替换结果分别报告。

### 5.2 要寻找的基线类型，以及它们能验证什么

下表是筛选目标，列出的配置是便于对照的典型形式，不是对尚未选定论文的事实描述。候选算法若更复杂或跨越多种类型，按实际结构填写维度。

| 待找类型 | 关系来源 | 图表示与融合 | 选点依据 | 与本文相同之处 | 最关键的差异和用途 |
|---|---|---|---|---|---|
| 规则型配置 | 无图或物理邻接 | 无学习融合 | 随机、覆盖、中心性或固定排序 | 相同预算与预测任务 | 对 B0，判断任务学习是否值得 |
| 节点任务选择 | 无显式节点对关系 | 节点历史编码 | 下游预测收益训练的节点评分 | 任务目标、输入和 Top-K | 对 BI，检查显式关系生成的增量 |
| 固定图任务选择 | 道路/相关图 | 普通 GNN 或图聚合 | 下游任务评分 | 有图、时空编码及预算选择 | 对 BC/BI，区分普通图信息与因果/意图关系 |
| 普通任务图学习 | 从历史按任务损失学习图 | 单图、普通关系编码 | 任务训练的关系或节点分数 | 数据驱动关系、任务反馈 | 对 BI，检验意图的特定表示或监督；若计算相同就不能当成不同机制 |
| 因果结构选择 | 因果或稳定核心图 | 单一结构、普通评分 | 结构重要性或任务收益 | 使用 C 及预算 | 对 BC/BCI，检验当前任务关系是否补充稳定结构 |
| 简单多图方法 | 两种互补关系，如结构先验+任务图 | 拼接、相加或固定权重 | 相同任务选择 | 多来源关系 | 对 BV/BF，检验派生视图和条件融合，而不是仅比较“图多不多” |
| 多视图时空方法 | 多来源或派生视图 | 专门的视图编码；简单或图级融合 | 节点/集合评分 | 多视图、时空表示 | 对 BE/BF，检验本方案的特定视图及局部门控 |
| 分层或局部融合方法 | 多关系图 | 图/节点/边中的多级门控 | 任务评分 | 自适应融合 | 对 BF，判断我们的层级划分是否超出已有局部融合 |
| 集合优化方法 | 可使用与本文相同的价值输入 | 无需规定图模型 | 条件收益、冗余惩罚或组合优化 | 相同预算、评价目标 | 对 BS，判断 Top-K 是否限制效果；额外价值模型须披露 |
| 动态调度方法，支线 | 过去可见历史及资源状态 | 允许关系/评分更新 | 周期或事件触发获取 | 固定设备与有限获取预算 | 检验调整时机及费用，不与主线混成同一种任务 |

“寻找能验证某模块的算法”，应落实为**找与该模块相邻的竞争思路**。例如验证多视图，不只是找完全不用图的方法，而是找已经使用 C/I 两类关系但直接融合的方法；验证节点门控，应优先找已有全局融合的方案；验证边门控，应找已有节点局部调整或直接边融合的方案。

如果候选论文只提供部分观测预测器、不输出选点动作，把它放在 A 类预测器比较，或与同一个选择器组合后做完整系统比较。它不能单独证明部署模块优劣。

### 5.3 每个外部算法都要配一个“最近的内部版本”

选定论文后先填下表，再决定是否适合进入主比较。不同维度不能只填“有/无”：例如“图”需要记录来源、方向、时滞和是否随样本变化。

| 算法 | 输入结构 C/I/其他 | 节点/边输入组 | 视图集合 | 时空编码 | 融合层级 | 选择及更新 | 最近内部版本 | 尚未控制的差异 |
|---|---|---|---|---|---|---|---|---|
| 待找：简单多图方法 | 结构先验+任务关系 | 待核对 | 两张基础图 | 待核对 | 相加或固定权重 | 预算选点、主线固定 | BCI | 监督、编码器、参数量等逐项登记 |
| 待找：节点局部融合方法 | 待核对 | 待核对 | 待核对 | 待核对 | 图+节点 | 待核对 | GN | 输入图和时空编码是否相同 |
| 待找：任务图学习方法 | 学习关系图 | 待核对 | 单图 | 待核对 | 单图评分 | 待核对 | BI 的普通任务图替换版 | 是否存在真正不同的目标或表示 |

只有把差异限制到一个因素，才能较有把握地解释该因素的作用。实际外部算法往往差异不止一个，因此采用两份结果：保留原方法优势的完整系统比较，以及在公共接口上替换核心模块的机制比较。后者明确称适配/替换版本，不冒充原论文原版。

## 六 按层级执行，按对应关系汇报

层级是研究逻辑的顺序，不是要求每层都穷举所有组合。先完成基本模块和核心主张，再对有研究意义的父模块细分。预先保留主假设的失败判据，不能只深入分析有利结果。

| 阶段 | 先固定什么 | 本轮只改变什么 | 主要产出 |
|---|---|---|---|
| 0 基础协议 | 数据、划分、可见信息、预算、预测器、评价代码 | 核验方向、梯度、时间可用性与特征有效性 | 能合法回放的 B0 和公共实验配置 |
| 1 基本模块 | 最小输入 $N_0,E_0$、主线一次选点 | B0/BC/BI/BCI，再到 BV/BE/BF；集合选择按需单列 | 哪些大模块有增量，原假设是否值得继续 |
| 2 内部组件 | 图来源与父模块结构 | 节点/边辅助输入、节点/边门控、空间/时间编码等 | 明确增益来自父模块的哪一部分 |
| 3 特征组与视图 | 对应组件及其他输入组 | 时间、相关、异常等组；共识、残差等视图分别增减 | 特征/视图的用途与适用条件 |
| 4 单项与交互 | 组级结论与统一配置 | 最优时滞、源/目标统计等单项；少量关键 2×2；参数敏感性 | 去冗余、修正公式、选择可复现的简化版本 |
| 5 独立确认 | 冻结设计和阈值 | 在独立测试、第二数据集、其他预算/预测器上复核 | 效果与局限；负结果也记录 |
| 支线 动态 | 主线模型、预算和数据权限 | 先只放开重选，再加入历史变化视图/特征 | 区分重选收益与变化表示收益 |

第一层最小版本的结论和最终完整版本的删除结果可能不同。例如边特征在最小意图模型中有帮助，但在强时空编码器中可被替代。这不矛盾，应报告为条件贡献，不能概括成“边特征一直有效”或“一直无用”。

一个可直接执行的例子是**节点/边辅助特征的层级实验**：

| 实验要素 | 具体设置 |
|---|---|
| 1 目的 | 判断意图生成器是否需要辅助节点、辅助边输入，再定位哪组提供增量 |
| 2 自变量 | 第二层比较 $N_0/E_0$、$N_+/E_0$、$N_0/E_+$、$N_+/E_+$；第三层拆 N+ 与 E+；第四层拆有效组内单项 |
| 3 指标 | 主指标片段等权 30 分钟 MAE；辅助为节点/边实际收益排序、相应场景误差、时延与参数 |
| 4 控制 | 相同 C/I 结构接口、候选边、评分骨干与隐藏宽度、下游预测器、视图、门控、K 和训练预算；只改变辅助输入，记录参数量差异 |
| 5 数据单位 | 同一批两小时片段；变化与常规片段的分组规则提前固定 |
| 6 划分 | 训练期拟合所有统计；验证期筛选特征与配置；独立测试确认，禁止反复查看测试后改结构 |
| 7 配置 | 删除输入后重训评分路径；删边特征需同时处理 GAT 与边评分入口。另做注入位置实验时，仅改变规定入口 |
| 8 重复 | 首轮种子 0—4，方法间共享预测器、片段与故障实例；保存每组配置 |
| 9 分析 | 检验节点辅助增益、边辅助增益及交互；再做组级和单项配对比较；区间过宽时结论为证据不足 |
| 10 保存 | 输入清单、父版本、增删位置、特征值分布、训练记录、动作、预测、误差、费用及失败运行 |

设四组片段平均损失为 $L_{00},L_{10},L_{01},L_{11}$，则节点辅助在无/有边辅助时的改善分别为
$L_{00}-L_{10}$、$L_{01}-L_{11}$；
边辅助同理。若要声称超过简单叠加的互补，检验
$L_{10}+L_{01}-L_{00}-L_{11}$ 是否支持正值。
不能只报告 $L_{00}-L_{11}$ 就分别宣布两组都有效。

所有消融结果使用同一记录格式：

| 层级/父模块 | 当前版本 | 参照版本 | 唯一变化及依赖处理 | 改善哪类问题的假设 | 配对误差差值与区间 | 对应机制指标 | 增加的成本 | 结论 |
|---|---|---|---|---|---|---|---|---|
| 第三层/I/边相关组 | 长期+窗口相关 | 仅长期相关 | 在两个规定入口加入窗口相关；其他输入固定 | 近期关系偏离时更能找到有价值观测 | 待运行 | 边级收益排序，待运行 | 待运行 | 未验证 |
| 第二层/F/节点门控 | GNE | GE | 边门控新增节点门控输入，并训练其路径 | 局部异质性下优于仅直接边调整 | 待运行 | 区域故障误差，待运行 | 待运行 | 未验证 |

论文正文按第一层、第二层展示关键结果，第三层按特征组/视图整理，第四层及完整失败清单放附录。外部算法表同样列出图来源、表示、融合和选择维度，读者可以直接对应到内部参照。

统计仍采用配对比较，按天或事件块处理时间相关，训练种子差异单独报告。确认性比较提前登记并处理多重检验；探索性特征筛选与独立确认分开。“从粗到细”是为了让结论有依赖关系，并不意味着某层未显著就可以省略与核心主张直接有关的验证。
