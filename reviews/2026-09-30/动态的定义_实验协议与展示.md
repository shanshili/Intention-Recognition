# “动态”的定义、实验落地与展示

日期：2026-09-30。

依据：当前 260628 / 260731 实现、保存的 20260731_205742 运行摘要、近期论文原文。本次只做定义梳理、已有摘要分析和绘图，未重新训练模型。

## 1. 一句适合当前方案的定义

> 在固定候选有向图和已训练模型参数的条件下，根据每个时刻实际可获得的历史窗口，重新估计面向未来流量预测的节点间依赖权重，并据此更新激活边集合与预算选择结果。

这里的“动态”主要是**模型推断出的预测依赖和选择结果随输入状态变化**。不能直接推断道路物理连接发生了变化，也不能把分数变化视为已识别的真实因果机制变化。

应同时说明五件事：

1. **变化对象**：边权、边集合、融合权重还是部署动作。
2. **驱动信息**：日历、当前历史窗口、累计状态或新反馈。
3. **更新频率**：每小时、每个滑窗或事件触发。
4. **状态记忆**：是否显式使用上一张图或上一轮动作。
5. **参数更新**：推断时是否重新训练参数。

## 2. 当前哪些部分动态，哪些部分固定

| 对象 | 当前实现 | 可支持的描述 |
|---|---|---|
| 节点与坐标 | 固定的 100 个传感器 | 固定空间节点 |
| 候选边集合 E0 | 坐标双向 KNN，训练后固定 | 固定候选支持 |
| 静态边特征 | 几何及训练期相关统计 | 固定先验属性 |
| 节点历史输入 | 随窗口滑动更新 | 动态交通状态 |
| GAT 注意力 | 依节点/边输入重新计算 | 输入相关空间聚合 |
| 最终边分数 s(t) | 每窗口重新计算 | 动态预测依赖权重 |
| 意图图激活边 | 每窗口分位数筛选 | E0 内的边激活变化 |
| 外部因果图 C | 当前加载后固定 | 长期先验 |
| 七视图与融合系数 | 随意图图、历史输入变化 | 状态相关融合 |
| 最终部署 | 每时刻独立按预算选择 | 时变选择结果 |
| 模型参数 θ | 测试时固定 | 没有在线参数学习 |
| 跨动作控制 | 当前缺少切换成本与动作状态建模 | 尚未验证完整的序贯部署策略 |

GAT 注意力与最终意图边分数是两个不同中间量，不能混用其可视化与解释。

### 2.1 固定参数也可以输出动态图

记可用历史为 $\mathcal H_t$：

$
s_{ij,t}=g_\theta(\mathcal H_t,e_{ij}),\quad (i,j)\in E_0.
$

$
I_t(i,j)=s_{ij,t}\mathbf 1[s_{ij,t}\ge Q_{0.9}(s_t)].
$

theta 固定，但不同历史产生不同分数；通过筛选，边的存在状态也可以改变。需要明确这里的不存在是“未激活/未保留”，不表示道路物理断开。

单看 sigmoid 后的连续分数，在有限输入、无数值下溢时，每条候选边通常仍为正。严格的支持变化主要发生在筛选或预算选择之后。

### 2.2 当前属于窗口条件化的动态

可以区分三种一般实现：

$
\text{窗口条件化：}\quad I_t=g_\theta(\mathcal H_t)
$

$
\text{带图状态：}\quad I_t=g_\theta(\mathcal H_t,M_{t-1}),\quad
M_t=U(M_{t-1},\mathcal H_t)
$

$
\text{在线学习：}\quad \theta_t=V(\theta_{t-1},\text{已到达反馈})
$

当前主要属于第一种。输入窗口本身包含历史，但没有独立累积图状态；这与第二种显式状态记忆不同。

三者不是天然的质量等级。增加记忆可抑制抖动，也可能延迟对突变的响应；在线更新还涉及反馈延迟、漂移检测与遗忘。

### 2.3 窗口内动态图与窗口间动态图

当前 RA 每个历史步都使用同一张当前视图：

$
Z_{m,\tau}=\operatorname{GNN}(X_\tau,A_m^t).
$

若要研究历史结构序列，需要改为：

$
Z_{m,\tau}=\operatorname{GNN}(X_\tau,A_m^\tau).
$

当前代码支持的是“每个窗口换一张图，并用它编码这个窗口”。不要将其描述为已经处理了每个历史时刻的结构演化。

## 3. 在具体实验中怎样落地

### 3.1 先固定时间语义

当前已保存 DEIG 运行：

- 小时级数据；
- W=3，H=1；
- stride=1；
- 每前进一个小时生成一张面向下一小时预测的图。

例如：

| 决策/观测截止时间 | 输入流量 | 生成图 | 预测目标 |
|---|---|---|---|
| 11:00 | 09:00、10:00、11:00 | I11 | 12:00 |
| 12:00 | 10:00、11:00、12:00 | I12 | 13:00 |
| 13:00 | 11:00、12:00、13:00 | I13 | 14:00 |

当前导出文件用预测目标起点标注 intent_time，所以图标签 12:00 可能对应表中 I11。展示时应同时保留观测截止时间与目标时间，避免误以为图使用了尚未发生的数据。

对于预算采样任务，选择动作必须基于选择前真正可见的信息。若在 t 时刻采样前做动作，应使用 $\mathcal F_{t-1}$ 及明确允许的外部背景信息；不能先读取所有昂贵的 $X_t$ 再宣称主动选择了它们。

### 3.2 顺序回放协议

1. 因果发现、静态统计、标准化和模型拟合遵守训练边界。
2. 验证集选择窗口、阈值、模型和超参数。
3. 测试时固定参数，按时间顺序逐窗口推断。
4. 在每个时刻保存原始边分数、激活边、门控、部署动作和预测。
5. 若模型有历史图状态，使用预先规定的初始化和更新顺序。
6. 等目标真实值到达后再计算误差；若有在线训练，也只能用已到达反馈。

无状态模型可以批处理测试窗口。有状态模型不能打乱测试顺序，更不能把未来窗口状态传回过去。

### 3.3 核心对照：动态是否必要

| 版本 | 图的来源 | 要回答的问题 |
|---|---|---|
| 固定图 | 训练期估计，或训练期图均值 | 随时间变化是否必要 |
| 周期图 | 只按小时、星期选择训练期估计图 | 收益是否仅来自周期规律 |
| 当前状态动态图 | 根据当前可用历史生成 | 当前状态是否提供周期之外的信息 |
| 状态记忆动态图 | 在上一图状态上更新 | 记忆和平滑能否改善噪声/长期漂移 |
| 可选：延迟图诊断 | 使用过去 k 步的图 | 及时更新是否重要 |

固定图、周期图和动态图应使用同一候选范围、相同下游信息和预算，并尽量控制骨干与模型容量。公平的替代版本要重新训练；临时冻结已训练模型中的图只是一种敏感性诊断。

不能用测试期平均图构造“静态基线”。延迟图必须来自过去；用未来图错位或任意跨测试时间洗牌只能是明确标注的信息破坏诊断，不能冒充可部署基线。

### 3.4 必须区分“有变化”和“有收益”

对一段测试序列，可报告如下指标：

**边权变化：**

$
D_w(t)=
\frac{\|I_t-I_{t-1}\|_1}
{\|I_t\|_1+\|I_{t-1}\|_1+\epsilon}.
$

这里矩阵 L1 指所有元素绝对值之和。对非负图该量近似在 0–1 之间，表示相对变化。应在固定节点顺序、固定权重尺度下计算，并区分原始分数与归一化后权重。

**边集合变化：**

$
D_E(t)=1-\frac{|E_t\cap E_{t-1}|}{|E_t\cup E_{t-1}|}.
$

两者都为空时规定变化为 0。它测量关系替换，而不依赖边总数是否变化。

**部署切换：**

$
D_a(t)=\|a_t-a_{t-1}\|_1/N.
$

它记录启用和停用比例。更多切换不是更好的目标。

**任务收益：**

$
\operatorname{Gain}
=\operatorname{MAE}_{static}-\operatorname{MAE}_{dynamic}.
$

正值表示该条件下动态图模型误差更低。还应分平稳、高峰、突变、分布漂移、故障等条件报告；这些场景标签应有独立依据。除准确性外，报告推断时间和切换成本。

如果研究真实结构识别，需额外使用有真实依赖结构的仿真或其他独立机制证据，测边恢复、变化检测延迟、稳定期误报。预测误差下降不自动证明恢复了真实因果图。

### 3.5 当前工程应先处理的三个障碍

1. **动态滞后特征失效**：W=3 小于当前相关估计的有效样本要求，但学习出的 h_i、s_ij 仍然可以随窗口变化，不能据此说整个图是静态的。
2. **分位数造成接近固定边数**：应该分析边身份替换和分数轨迹，不能只看密度。
3. **最终部署图缺少任务反馈**：上游 DEIG 的边进入预测；当前 RA 的最终 S/部署选择不进入预测链路。要验证动态部署收益，先让选中观测或图实际影响预测。

## 4. 如何展示“动态”：建议用四组图建立证据链

### 图一：交通状态—边权—误差，时间轴对齐

选择预先规定的代表性有向节点对，把同一段时间画成三个面板：

- 两端流量或去周期残差；
- $s_{ij,t}$ 与 $s_{ji,t}$ 的连续轨迹，及筛选阈值；
- 固定图与动态图的滚动误差差异。

有独立事件记录时标注事件时间；没有事件真值就标注观测到的状态变化，避免把模型自身的高分循环解释成真实事件。

价值：展示哪些变化与模型权重响应同步，并观察对应时段是否有收益。它仍然是案例证据，须配合全测试集统计。

### 图二：固定边顺序的“边 × 时间”热力图

- 横轴：连续时刻；
- 纵轴：固定的一批有向候选边；
- 颜色：原始分数或明确定义的归一化权重；
- 可另画二值激活热力图。

不要每列重新排序边，否则会掩盖同一条边的轨迹。不要逐列自动缩放色域，否则平稳值也会显得变化剧烈。

若边很多，主图展示训练/验证期预选的代表性边，或披露选择案例的方法。全体边的变化分布应一起报告。

### 图三：同一空间布局的连续图快照

展示固定时间间隔或独立事件前、中、后的 3–4 张图：

- 节点坐标、视野、箭头比例、线宽标尺固定；
- 持续边：灰色；
- 新激活边 $E_t\setminus E_{t-1}$：突出颜色；
- 消退边 $E_{t-1}\setminus E_t$：另一颜色虚线；
- 每图写清观测截止和预测目标时间。

不能每帧重新跑随机布局，否则节点移动会制造视觉上的“动态”。物理坐标本来固定时，动画只应改变边及节点状态。

热点轨迹若需跨窗口连线，应根据节点集合重合进行匹配，并处理分裂/合并；不能把每帧按强度排序后的“热点 1”当成同一个实体。

### 图四：融合与部署随时间变化

用于 RA-TCGF：

- $\pi_m(t)$：各视图融合系数折线或堆叠图；
- $a_{i,t}$：节点 × 时间的激活矩阵；
- 同步显示预算使用、切换次数和预测误差；
- 故障实验中标记真实失效区间。

门控系数表示模型内部偏好，不直接表示“因果机制成立概率”。当前存在训练反馈断开的问题时，这类图首先是内部行为诊断。

### 最适合论文的一组组合

主文建议优先放：

1. 节点状态＋有向边权轨迹；
2. 三个固定布局图快照；
3. 图变化指标与部署切换；
4. 同预算的分场景性能对照。

动画可用于演示，但论文仍需静态证据和完整统计。目标是说明模型是否在合适的时候调整了合适的关系，以及这是否带来可重复的收益。

## 6. 2025–2026 年近期研究：怎样定义、实现和验证动态

### 6.1 DST-SGNN，IJCAI 2025：输入驱动的关系矩阵

**A Dynamic Stiefel Graph Neural Network for Efficient Spatio-Temporal Time Series Forecasting**

该文对窗口做 patch 与季节/趋势分解，在其图表示上定义：

$
A_t=I+E_tE_t^\top,\qquad E_t=\operatorname{ReLU}(X_t^{emb}).
$

邻接随输入表示重算，再通过 Stiefel 约束下的低维变换实现图谱卷积。这里的关系是对称的，图表示涉及 patch；它不能直接当作本工程的有向传感器图。

借鉴点是：明确动态图由什么输入生成，以及频繁更新的计算代价。该文以预测、组件消融及效率评估为主，不应把名称中的“动态”直接视为物理拓扑识别证据。[会议页](https://www.ijcai.org/proceedings/2025/796)；[原文 §4.4.2](https://arxiv.org/html/2506.00798v1)

### 6.2 GC-MGT，2026：固定先验上的动态边权与融合

**A Granger causality-guided multi-graph transformer framework for traffic flow forecasting**

其先验修正：

$
A_t^C=A_{\rm Granger}\odot\sigma(f_\theta(X_{t-T+1:t})).
$

论文明确先验离线拟合，该分支更新权重而不改变支持。它还构造动态语义关系、状态相关多图融合，并让融合图进入预测注意力。

验证中比较静态先验与动态修正、固定与自适应融合等版本，并使用 SUMO 做传播一致性诊断。该文适合参考“动态如何实际参与预测”和动态/静态消融。它的因果先验分支与整套多图系统应分别描述。[原文 §3.3、§5.3，2026-09-22](https://link.springer.com/article/10.1007/s44163-026-02230-y)

### 6.3 DynaSTar，IJCAI 2026：历史图状态与稀疏结构

**Tracking Topological Shifts: How Can Dynamic Graph Invariant Learning Enable Reliable Out-of-Time Spatio-Temporal Prediction?**

先计算当前关系，再维护动量图原型：

$
M_t=\beta M_{t-1}+(1-\beta)G_t,\quad P_t=\sigma(M_t).
$

训练时用 Straight-Through Gumbel-Softmax 处理稀疏边采样，推断时按概率阈值生成图；原型在每次预测后更新。

该文展示一对节点 40 天流量及边概率热力图，并用跨时间泛化和去除动量、稀疏生成等实验检验收益。其图状态更新不能等同于在线重新训练全部参数。[论文 §4.1、动态图分析及图 5](https://www.ijcai.org/proceedings/2026/0296.pdf)

这是当前最值得学习的“状态曲线＋边权响应＋组件对照”展示方式；单独案例仍不足以证明关系的因果真实性。

### 6.4 三者与当前方案的对照

| 方法 | 变化机制 | 显式历史图状态 | 对本工程的主要启发 |
|---|---|---|---|
| 当前 DEIG | 滑窗表示→边分数→筛选 | 无独立累计图状态 | 已具备窗口条件化动态，可先验证是否优于静态/周期图 |
| DST-SGNN 2025 | 输入表示→关系矩阵与谱变换 | 上述构造不依赖上一图原型 | 输入驱动与更新成本 |
| GC-MGT 2026 | 固定先验×动态修正，多图融合 | 核心修正不依赖上一图原型 | 图进入预测及静态/动态消融 |
| DynaSTar 2026 | 当前关系＋动量原型→稀疏图 | 有 | 历史记忆、变化响应、长期泛化 |

SGSL 2025 仍可作为任务驱动图学习参考，但本次未取得其完整方法正文，不依据“周期性训练更新”推断其具体在线图更新协议。[机构页](https://discovery.ucl.ac.uk/id/eprint/10205456/)

## 7. 当前最小实施清单

### 可直接完成的数据记录

每个时刻保存：

- node_ids、candidate_edges、观测截止与预测目标时间；
- 原始 s_t、实际用于消息传播的权重、筛选阈值与激活边；
- 融合权重、最终部署节点/边、成本；
- 预测、目标及逐样本误差；
- 状态初始化/更新记录、随机种子与模型版本。

### 最小实验包

1. 恢复原始边分数，先画连续轨迹与固定布局快照。
2. 训练固定图、周期图、当前窗口动态图三个可比版本。
3. 报告全测试集及变化时段的 MAE/RMSE、图变化和运行代价。
4. 若抖动明显，再引入有历史状态的版本，比较收益与响应延迟。
5. 若主张动态部署，再加入真正部分观测、相同预算、切换成本与故障实验。

## 结论

当前方案可以合理称为“动态预测依赖图”，因为图分数和激活关系随历史窗口变化。更严谨的展示应沿着：

> **输入状态变化 → 模型关系调整 → 部署或预测行为变化 → 可重复的任务收益**
