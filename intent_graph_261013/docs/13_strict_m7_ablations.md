# M5 时间注意力扩展与 M7 严格消融

## 1. 范围与共同母模型

本轮落实设计文档第 6.1、6.2 节，不混入第 7 节损失消融，也不改变旧 M1–M7 的定义。共同母模型是 M7-L0：X7 节点输入、边感知 GAT、因果 TCN、时间注意力、包含静态及显式动态边特征的评分器、后置意图消息和残差预测头。L0 表示只有预测损失，而不是没有训练。

每个变体均从相同的结构定义出发，独立从头训练。它不是从已训练 M7 检查点删模块后直接测试，也不是继续微调旧模型。同一种子控制各次随机初始化和批次次序；结构变化改变随机数消耗，不能宣称所有共同参数初值逐位一致。参数数量允许随删减变化，并由效率汇总实际记录。

## 2. 新增 M5＋时间注意力

入口名称为 m5_attention，等价别名为 m7_no_dynamic_edge。模型仍产生随历史窗口变化的边分数，只是不显式计算和拼接六维动态边特征。

设 GAT–TCN 的历史序列表示为 \(q_{i,\tau}\)，则

$$
\beta_{i,\tau}=\frac{\exp\{a(q_{i,\tau})\}}{\sum_{u=1}^{W}\exp\{a(q_{i,u})\}},
\qquad z_i=\sum_{\tau=1}^{W}\beta_{i,\tau}q_{i,\tau},
$$

$$
s_{ij}=\sigma\!\left(f_{\mathrm{edge}}([z_i\Vert z_j\Vert z_i-z_j\Vert z_i\odot z_j\Vert e_{ij}])\right).
$$

它与 M5 的区别仅为末端读取变成时间注意力；与 M7 的区别仅为评分器不接收显式动态特征。与 M6、M7 一起可构成二因素对照：

| 时间汇总 | 不含显式动态边特征 | 含显式动态边特征 |
|---|---|---|
| TCN 末端读取 | M5 | M6 |
| 时间注意力 | M5_ATTENTION | M7 |

这组结果可以区分注意力本身的收益，以及它是否主要补偿了动态边特征的不利影响。所有比较应采用相同数据、训练预算和种子；历史结果如训练参数不同，应标注差异，不能自动当作严格对照。

## 3. 严格消融的全部入口

| 规范输出名称 | 与 M7 相比的修改 | 保留内容与解释 |
|---|---|---|
| m7 | 无，母模型 | 也接受 m7_l0、m7_dynamic_intent |
| m7_no_gat | 逐时刻节点投影替代 GAT | 没有前置空间混合，后置邻居消息仍在；不等于 Local |
| m7_no_tcn | 逐时刻映射替代 TCN | 保留历史序列与时间注意力；不是完全无时间信息 |
| m7_no_extra_node_features | GAT 仅输入流量通道 | 完整 X7 历史仍供动态边特征计算使用 |
| m7_no_gat_edge | 静态边特征不进入 GAT | 静态边特征仍进入评分器 |
| m7_no_score_edge | 静态边特征不进入评分器 | GAT 仍为边感知 GAT，动态边特征仍在 |
| m5_attention | 删除显式动态边特征 | 等价别名 m7_no_dynamic_edge |
| m6 | 时间注意力替换为末端读取 | 等价别名 m7_no_temporal_attention；结构与已有 M6 一致 |
| m7_no_intent | 删除后置消息与评分器 | 保留 GAT、TCN、时间注意力；只输出预测，不导出无监督的随机边分数 |

同一运行中不能同时选择规范名及其别名。全套默认 11 个不同模型、3 个种子，共 33 次训练。无消息、固定、静态和动态四种机制组成第 6.2 节对照，已经包含在全套里，不重复计算。

## 4. 删除与替换的数学定义

无 GAT 时使用共享的节点局部映射

$$h_{i,\tau}=\operatorname{ELU}(W_x x_{i,\tau}),$$

保持后续 TCN 输入宽度，不读取其他节点。无 TCN 时使用

$$q_{i,\tau}=\operatorname{ReLU}(W_q h_{i,\tau}+b_q),$$

不同历史位置不通过该映射混合，之后仍由时间注意力汇总。

无额外节点特征只将 GAT 输入改为 \(x_{i,\tau}=[z_{i,\tau}]\)。评分分支的残差、趋势等来源保持原定义，避免同时删除两种输入。运行元数据分别记录原始历史通道与进入空间编码的通道，不能仅凭数据保存为七通道判断该消融无效。

四种后置意图机制为

$$
s_{ij}=\begin{cases}
\text{不定义},&\text{无后置消息},\\
1,&\text{固定消息},\\
\sigma(\theta_{ij}),&\text{静态意图},\\
\sigma(f_{\mathrm{edge}}(z_i,z_j,e_{ij},d_{ij})),&\text{动态意图}.
\end{cases}
$$

除无消息版本外，传播规则始终为

$$g_j=\frac{1}{\max(1,\deg^-_{G_0}(j))}\sum_{i:(i,j)\in E_0}s_{ij}W_m z_i.$$

无消息版本令 \(g_j=0\)，保留预测头输入中的同宽零消息槽；删除评分器与消息投影参数，不将随机评分作为解释输出。所有版本的预测仍为

$$\hat Y_j=Y_j^{\mathrm{last}}+f_{\mathrm{head}}([z_j\Vert g_j]).$$

## 6. 损失与保存规则

全部严格消融默认使用标准化目标上的掩码 Huber 损失，转折点为 1：

$$\mathcal L=\frac{\sum m_{bih}\operatorname{Huber}_1(\hat y_{bih}-y_{bih})}{\sum m_{bih}}.$$

稀疏、方向、时间平滑三个损失权重均为零。早停及最佳模型选择仍看完整验证集标准化 MAE。每个 epoch 打印预测损失、总损失、验证指标及早停状态，不因新增模型而省略。

结果写入新的 outputs 下 suite 时间戳目录，不覆盖历史结果。experiment_design.json 记录严格消融母模型、模型名单、训练和评估配置。run_summary.json 记录实际结构、能力、参数数量及训练状态；resolved_config.json 记录展开的配置；各模型、种子的 train、val、test 均保存完整预测与适用的门控。组级报告在每次完成一个模型种子后刷新，全部完成后 suite_summary 状态为 completed。

无消息版本不产生 edge_scores.npz，连续意图图绘制标为不适用；固定版本保存全一边权但没有有意义的 Top-K 排名；静态版本跨窗口分数相同，不应称为动态意图图。已有自动连续绘图、离线补绘、筛选及命名方式保持一致。

## 7. 如何判断组件有效

预测收益以同一测试集母模型与消融模型的差值衡量：

$$\Delta_{-c}=\mathrm{MAE}_{M7\setminus c}-\mathrm{MAE}_{M7}.$$

正值表示删除该组件后变差；负值表示删除后更好。应同时列出每个种子差值、均值与离散程度、三个预测时距、RMSE、训练成本及适用的边忠实度，不能只根据一次均值宣称组件有效。

删边／留边干预仍仅作用于后置消息通路，前置 GAT 保持不变。No Intent Message 是重新训练的结构对照，不等于对已训练 M7 做一次全消息关闭干预。无边级真值时，预测增益和干预忠实度不能证明恢复了真实因果边。

本轮未实现可选的 TCN→GAT 顺序实验、L1–L4 损失消融批处理或前后两条空间通路的联合干预。测试与小规模运行仅证明实现可运行；不代表 30 天、100 轮正式对照已经完成。
