## 4. 四个神经模型为何完全等于 Persistence

神经预测采用残差形式：

$$
\hat z_{t,j,h}=\bar z_j^t+\hat r_{t,j,h}.
$$

最后输出层初始化为零，因此第 0 轮的 $\hat r$ 为零，恰好对应 Persistence。训练器将第 0 轮纳入最佳验证状态，不强制采用已经训练但验证更差的参数。

本次两个训练 epoch 后，四个神经模型的验证 MAE 均未低于第 0 轮 0.128946。因此均恢复第 0 轮，最终预测精确等于 Persistence。

这表明最佳状态保存与恢复按约定工作，同时表明本次运行没有取得神经预测增益。两轮、一个训练种子、两天前缀的数据量太小，不能据此判定图基本单元无效；也不能将“流程跑通”误称为模型有效。

## 5. 边干预与门控诊断结果

StaticGate 与 DynamicGate 的三个预算均完成了 Top、Low 和 20 次 Random 的删除与保留。所有干预后的 MAE 都等于 14.881316，因此有符号差值、随机种子标准差与随机校正均为 0。关闭整个消息通道的差值也为 0。

这是恢复零输出层后的必然结果：预测残差不依赖任何隐表示或图消息，关闭图消息不会改变预测。它不能证明高分边具有必要性或充分性。

StaticGate 恢复为初始 0.5 的常数门控。其验证正分数 90% 阈值为 0.5，采用大于等于阈值的规则会保留全部 488 条正分数边。这里不是零阈值错误，而是全部正分数并列；因此精确 Top-K 与常数窗口诊断仍然必要。

DynamicGate 的测试门控范围为约 0.535749 至 0.582009，零分与近零比例均为 0。验证阈值约为 0.551628，测试平均候选密度约为 0.112435，空阈值图窗口比例约为 0.096491。

DynamicGate 的相邻 Top-5%、Top-10%、Top-20% Jaccard 均值分别约为 0.752215、0.687712、0.714724，连续分数平均变化约为 0.000858。因为恢复的是初始化模型，这些变化来自随机初始化的门控网络对不同历史输入的响应，不能当作训练识别出的动态意图。
