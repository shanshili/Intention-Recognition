# 参数、损失分量与逐级实验

## 1. 数据协议参数

| 参数 | 默认值 | 数学或实验含义 |
|---|---:|---|
| 原始采样间隔 $\Delta$ | 5 分钟 | 目标时间与日历网格的间隔 |
| 历史长度 $W$ | 12 | 每节点可见的历史采样数 |
| 预测长度 $H$ | 3 | 直接预测未来 5、10、15 分钟 |
| 时间切分 | 0.6／0.2／0.2 | 训练、验证、测试目标范围 |
| 训练 stride | 3 | 相邻训练窗口原点间隔 15 分钟 |
| 验证、测试 stride | 1 | 相邻评价窗口原点间隔 5 分钟 |
| 候选 KNN 的 $k$ | 4 | 每节点选择的初始近邻数；之后取双向并集 |
| 候选滞后统计上限 $\tau_{max}$ | 4 | 训练期可选边统计的滞后搜索范围 |
| 节点特征 | 水平值 | 差分、时间和周期残差默认关闭 |
| 标准差判定阈值 | $10^{-6}$ | 更小的训练标准差使用单位尺度 |

| 协议文件 | 默认前缀范围 | 目的 |
|---|---:|---|
| `protocol_smoke.json` | 576 行，2 天 | 检查完整流程与输出，不能据此确立正式结论 |
| `protocol_dev.json` | 8640 行，30 天 | 基本模型与参数开发比较 |
| `protocol_full.json` | 61056 行，212 天 | 开发选择确定后的正式比较 |

真实读取范围可能受数据行数或显式覆盖设置限制，实际范围以产物中的展开协议为准。开发与全量协议是不同实验；比较程序不将二者混为一个排名。

改变 $W,H$、可用特征、训练切分、候选图或缺失规则需要生成新的协议。测试集保持为最终检验范围；模型与参数选择只使用训练和验证。

## 2. 模型与训练默认参数

| 参数 | 默认值 | 用途 |
|---|---:|---|
| 编码器 | 两层 MLP | 本节点历史表示 |
| 编码隐藏维度 | 24 | 两层 MLP／可选 TCN 的通道维度 |
| 消息维度 | 16 | 空间消息内容维度 |
| 预测头隐藏维度 | 32 | 预测残差前的非线性映射 |
| 动态门控隐藏维度 | 32 | 共享边配对网络的隐藏维度 |
| 神经训练种子 | 0、1、2 | 初始化与训练批次排列重复 |
| 最大 epoch | 50 | 单模型、单种子的训练上限 |
| 提前停止 patience | 5 | 连续验证未改善的轮数上限 |
| 训练 batch 大小 | 32 | 优化批次上限，不丢尾批 |
| 评价 batch 大小 | 128 | 预测与干预批次上限，不改变评价集合 |
| Adam 学习率 | $10^{-3}$ | 神经参数更新步长 |
| 权重衰减 | 0 | 默认不附加参数尺度惩罚 |
| 梯度范数裁剪上限 | 5 | 控制过大的单次梯度 |
| 验证改善最小量 | 0 | 严格小于历史最佳 MAE 即视为改善 |
| CPU 计算线程 | 2 | 运行资源设置，不改变数学模型 |
| 神经计算设备 | 自动选择 | CUDA 可用时使用 GPU，否则使用 CPU |
| 严格确定性 | 关闭 | 避免将不支持的确定性 CUDA 操作静默替换 |

Persistence 只执行一次确定性评价，不用不同种子重复完全相同的结果。Ridge-AR 不经过 epoch；其 $\alpha$ 候选为 $\{0.01,0.1,1,10\}$，通过完整标准化验证 MAE 选择。

神经模型训练停止与最佳轮次以完整、有效元素加权的标准化验证 MAE 为准。最佳状态保存独立参数副本，验证改善时重置连续未改善计数，最后恢复最佳状态后评价测试。

设备也可明确指定 CPU 或 CUDA。明确指定 CUDA 但不可用时停止并报告环境问题，避免静默运行在与要求不同的设备上。数据预处理和 Ridge 求解仍使用 CPU；设备选择不改变损失公式与评价窗口。GPU 显存不足时优先降低 batch 大小，记录该变化，而不缩短评价范围或丢弃尾批。

当前神经计算使用单精度浮点，未启用自动混合精度。严格确定性开关启用时，PyTorch 对没有确定性实现的操作可以报错；它不保证 CPU 与 GPU 的训练结果逐位一致。

### 2.1 可训练参数量计算

令历史展开维度为 $p=WF$，编码维度为 $d$，消息维度为 $m$，预测头隐藏维度为 $q$，门控隐藏维度为 $r$。两层 MLP 编码器参数量为

$$
P_{enc}=pd+d+d^2+d=pd+d^2+2d.
$$

无偏置消息投影和预测头分别有

$$
P_{msg}=dm,
\qquad
P_{head}=(d+m)q+q+qH+H.
$$

因此基础四模型的参数量为

$$
\begin{aligned}
P_{Local}&=P_{enc}+P_{head},\\
P_{Fixed}&=P_{enc}+P_{msg}+P_{head},\\
P_{Static}&=P_{Fixed}+E,\\
P_{Dynamic}&=P_{Fixed}+4dr+2r+1.
\end{aligned}
$$

Local 的头保留与其他模型相同的 $d+m$ 输入维度，其消息部分始终为零；这里报告的是实际被注册为可训练参数的数量，不将零输入对应的头权重扣掉。门控网络增加了参数，因此动态模型与静态模型不是严格相同参数预算；实验应同时报告参数量与运行耗时。

默认 $F=1,W=12,H=3,d=24,m=16,q=r=32$ 时，Local 为 2323 个参数，FixedGraph 为 2707 个，StaticGate 为 $2707+E$，DynamicGate 为 5844 个。候选图边数由数据决定。

当前两层 TCN 的参数量为

$$
P_{enc}^{TCN}=3Fd+d+3d^2+d=3Fd+3d^2+2d,
$$

使用它时替换上述 $P_{enc}$。Persistence 模型参数量为零；Ridge-AR 对每个节点与 horizon 学习 $p$ 个系数和一个截距，模型参数量为 $NH(p+1)$。共同标准化统计不计入某个模型的可训练参数量。

## 3. 默认预测损失

令标准化预测误差为

$$
e_{t,j,h}=\hat z_{t,j,h}-z_j^{t+h}.
$$

Huber 损失为

$$
\ell_\delta(e)=
\begin{cases}
\frac12e^2,& |e|\le\delta,\\
\delta\left(|e|-\frac12\delta\right),& |e|>\delta.
\end{cases}
$$

默认 $\delta=1$，在训练标准化尺度上解释。单个训练批次 $\mathcal B$ 的预测损失为

$$
\mathcal L_{pred}=
\frac{\sum_{t\in\mathcal B,j,h}M_{t,j,h}\ell_\delta(e_{t,j,h})}
{\sum_{t\in\mathcal B,j,h}M_{t,j,h}}.
$$

也可以使用 MAE 损失，将 $\ell_\delta(e)$ 换成 $|e|$。训练损失与正式原始单位 MAE 不是同一数值，应分别报告。全部目标缺失的训练批次跳过；不能只用这一批的图正则推动门控收缩。

## 4. 可选图正则

完整损失为

$$
\mathcal L=
\mathcal L_{pred}
+\lambda_s\mathcal L_{sparse}
+\lambda_d\mathcal L_{dir}
+\lambda_t\mathcal L_{temp}.
$$

第一版默认

$$
\lambda_s=\lambda_d=\lambda_t=0.
$$

不启用图正则时，学习边门控本身是否提供预测增益更容易判断。后续每次只打开一个分量，再检查预测与干预证据是否改善。

### 4.1 稀疏门控项

对训练批次的门控均值惩罚：

$$
\mathcal L_{sparse}=
\frac{1}{|\mathcal B|E}
\sum_{t\in\mathcal B}\sum_{e\in E_0}a_e^t.
$$

它鼓励较小门控，但并不直接保证精确 $K$ 条边，sigmoid 门控也不保证出现精确零。与预测收益存在权衡。仅在 StaticGate 或 DynamicGate 上有意义；Local 与全一 FixedGraph 不启用该项。

不应将“均值更小”自动解释为学到更真实或更稀疏的物理关系。检查门控分布、消息规模、完整预测误差与干预效应，防止模型通过其他权重补偿尺度。

### 4.2 双向共激活项

令 $\mathcal P$ 为双向候选边对应的无重复配对，每对只计一次：

$$
\mathcal L_{dir}=
\frac{1}{|\mathcal B||\mathcal P|}
\sum_{t\in\mathcal B}\sum_{\{i,j\}\in\mathcal P}
a_{ij}^ta_{ji}^t.
$$

它减少双向同时强激活，是一个建模先验，不是证明物理传播单向的约束。交通网络可能确有双向关系，故默认关闭。没有双向配对时该项为零。

### 4.3 相邻时间门控平滑

对同一训练分区中符合训练 stride 的相邻窗口 $(t',t)$，其中 $t'=t-s_{tr}$，定义

$$
\mathcal L_{temp}=
\frac{1}{|\mathcal A_{\mathcal B}|E}
\sum_{(t',t)\in\mathcal A_{\mathcal B}}
\sum_e|a_e^t-a_e^{t'}|.
$$

$\mathcal A_{\mathcal B}$ 是当前批次能够找到真实前序训练原点的有效配对集合。随机打乱后的批次相邻位置不是时间相邻，不能直接对其做平滑。训练器额外取真实前序历史，使用同一当前参数计算两端门控，两个端点都属于训练窗口。

此项仅用于 DynamicGate；StaticGate 原本恒定，加入平滑没有新增信息。跨分区、抽样断点或不存在前序窗口的原点不构造配对。有定义配对为空时该项为零。

过大的 $\lambda_t$ 可能使 DynamicGate 接近静态图，掩盖突发变化。检查平滑项效果时应同时看预测、边排名、Jaccard 和连续分数变化。

## 5. 梯度裁剪与优化含义

若全部参数的梯度向量为 $\mathbf g$，裁剪上限为 $G=5$，则

$$
\mathbf g_{clip}=\mathbf g\min\left(1,\frac{G}{\|\mathbf g\|_2+\varepsilon}\right).
$$

裁剪用于控制数值更新幅度，不改变训练监督定义。非有限损失或梯度应停止并给出诊断，不能将其静默替换为零继续输出结果。

## 6. 评价参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| Top/Low 边比例 | 0.05、0.10、0.20 | 每窗口精确向上取整预算 |
| 随机干预重复数 | 20 | 每个预算分别评价随机选边基准 |
| 随机干预种子 | 0 至 19 | 固定已训练模型的选边重复 |
| 探索阈值正分位数 | 0.9 | 仅从验证正门控选取，空集合停用 |
| 固定绝对阈值 | 未指定 | 若预先指定则优先于验证正分数分位数 |
| 近零诊断阈值 | $10^{-8}$ | 分数小于或等于此值计入近零比例 |
| 图干预 | 开启 | 完整 Top／Low／Random 删除与保留评价 |
| 图干预分区 | 仅测试 | 训练、验证保存完整预测与门控，默认省略重复干预推断 |
| 图示窗口数上限 | 3 | 控制默认展示产物规模，不限制评价样本 |

图示窗口少不等于测试只评估几个窗口。主指标与边干预仍使用完整测试集合。需要大规模图示时，可以用保存的预测与门控产物扩展展示，避免为了改色标而重新训练。

调试时允许关闭图干预或减少随机种子数，以检查预测与保存链路。这种运行的评价签名不同，不可与默认 20 种子完整干预结果混作同一种实验。一个随机种子时标准差为空值。

三个分区都由恢复后的最佳模型完整评价并保存；这不是另行拟合三个模型。默认图干预分区集合为 $\mathcal S_{int}=\{test\}$，可在评价配置中设为 $\{train,val,test\}$。该设置进入评价签名，未指定分区的干预结果明确为未计算。

阈值从恢复后模型的验证门控确定一次并冻结，三个分区共同使用。不能因为训练与测试分布不同，就分别调阈值来达到相同边密度。默认图示仍只展示少量窗口，完整数组保存与图示上限分别控制；不为每个窗口默认生成 PNG。

## 7. 逐级实验顺序

| 阶段 | 固定因素 | 新增因素 | 判断条件 |
|---|---|---|---|
| A | 同一数据协议和评价 | Persistence、Ridge-AR | 取得可信完整基线 |
| B | 水平值、MLP、预测损失 | Local、FixedGraph | 空间消息是否优于自身历史 |
| C | 相同基本骨架 | StaticGate | 学习静态门控是否优于全一图 |
| D | 相同基本骨架 | DynamicGate | 动态是否比静态有稳定增益 |
| E | 仍只用预测损失 | 共同编码器换成 TCN | 时间编码改进是否普遍有效 |
| F | 已有效的门控骨架 | 一个节点或边特征组 | 增益是否来自该信息 |
| G | 已确定的特征与模型 | 一个图正则分量 | 是否改善泛化和排序，而不塌缩 |
| H | 已确定的数据协议 | 外部经典图模型、合成真值 | 扩展预测与结构识别对照 |

每一阶段都保存独立展开配置，不能覆盖前一阶段配置后只保留最终模型结果。数据和评价协议一致时才比较模型；特征或数据范围改变时，另开一组比较。

推荐先跑小型流程检查，再跑 30 天开发比较，最后冻结选择并跑完整数据。小型范围可以降低 epoch 和训练种子数，但结果只表明流程可运行，不意味着基本单元已经有效。

## 8. 多次训练结果汇总

对某模型三个训练种子的主指标 $m_1,m_2,m_3$，报告

$$
\bar m=\frac{1}{3}\sum_{r=1}^{3}m_r,
\qquad
s_m=\sqrt{\frac{1}{2}\sum_{r=1}^{3}(m_r-\bar m)^2}.
$$

同时保留每个种子的结果和最佳 epoch。三次重复能提供初步稳定性信息，但小差异未必显著；窗口误差高度相关，不能把数千个重叠窗口当成独立随机实验来夸大统计置信度。

先根据验证误差与预先固定的评价规则选择模型，再报告测试结果。不能反复看测试 Top-K 表调损失权重，并将最终测试提升称为独立泛化证据。
